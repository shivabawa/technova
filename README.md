TechNova — Electronics E-Commerce Website

TechNova is a modern electronics e-commerce website designed to provide users with an easy and engaging online shopping experience. The project features a responsive interface and reusable React components.

✨ Features

- Modern homepage and navigation
- Electronics shopping interface
- Product display sections
- Reusable UI components
- Responsive styling
- Interactive shopping interface


🛠️ Technologies Used

- React — Building the user interface
- JavaScript — Application logic and interactivity
- HTML5 — Page structure
- CSS3 — Styling and layout
- Vite — Development server and build tool
- Git & GitHub — Version control and collaboration

🚀 Getting Started

Follow these steps to run TechNova on your computer.

Prerequisites

Install "Node.js" (https://nodejs.org/) and Git.

Installation

1. Clone the repository:
   
   git clone https://github.com/shivabawa/technova.git

2. Navigate into the project folder:
   
   cd technova

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL shown in your terminal, usually "http://localhost:5173/".
